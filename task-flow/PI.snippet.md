## MEGAI task flow
Use Plane only for tracked work. At start, consume all paginated projects and project work items, require one exact Git-root project and one exact linked item, and reuse the `(project UUID, work item UUID)` pair. Imported items require `external_id` plus `external_source=asana-migration-v1`; preserve the original `<!-- asana:GID -->` marker until the pair is confirmed. The parent performs the started `In Progress` boundary before edits; an unavailable or ambiguous Plane boundary blocks changes. Run inspect → implement → self-review → focused verification. Hand off at started `In Review` with the item incomplete; only the user marks `Done`. No routine milestone comments, polling, or parallel tracker mirroring.
