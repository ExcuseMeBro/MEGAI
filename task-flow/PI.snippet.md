## MEGAI task flow
The parent loads `megai-task-flow` once at task start/resume and completes its Plane start boundary before project edits. Reuse the active linked work item through edits and follow-up refinements; delegated children inherit that identity and never mutate Plane or `.todos`. Resolve exactly one project by Git-root folder name, consuming every Plane project page; zero or multiple matches require the user. Resolve exactly one project work item the same way before mutation. Preserve the original `<!-- asana:GID -->` marker until its Plane pair is confirmed. Finish at Plane `In Review` with the work item still incomplete; only the user may mark `Done`.
