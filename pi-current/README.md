# Current Pi configuration — `for-ustama`

Point-in-time, shareable snapshot of the **user-level Pi-Bolt** setup on 2026-11-04. This directory is not an automatic installer. It does not change the active Pi runtime. The previous MEGAI repository source tree, including its old project-level `.pi/` files and OMP artifacts, is not part of this clean-history branch because it is not the current user-level Pi installation. The separate `/Users/bro/PROJECTS/.pi/project.json` belongs to a multi-repository workspace, not the current user-level Pi configuration.

## Included

- `agent/AGENTS.md`: current global agent instructions (the repository's older `pi-defaults/` may differ). Task delivery to dev has standing approval: after tests pass the agent syncs with dev, resolves conflicts, merges, pushes dev and removes the task worktree/branch without asking; uncommitted work is committed (WIP or `wip/` branch), a blocking process may be stopped by exact PID, and a repository without a Brokan project is still worked. Main, releases, tags and force-push still need explicit approval.
- `agent/settings.json`, `agent/models.json`: selected provider/model/thinking, package, prompt and skill selectors, theme, explicit model definitions. Built-in `+codemode` is enabled alongside the default read/bash/edit/write tools for bounded independent tool batches; shared writes and Git delivery remain serial. `models.json` currently has an empty providers map.
- `agent/mcp.template.json`: currently configured MCP servers/exposure/tool selectors, **with Authorization headers replaced by `<SET_LOCALLY>` and home paths marked `$HOME`**. This is a template, not a directly runnable credential file; substitute paths and configure private credentials locally.
- `agent/prompts/`: current command prompts (`/mdev`, `/prdev`, `/rwbrowser`); the retired Plane `/splane` prompt is gone with Plane. `agent/extensions/tgrep/`: local tgrep extension source (`index.ts` and its `search-policy.mjs` grep guard); tgrep live-scans by default with no index. `agent/skills/pi-workflow/SKILL.md` and `context-economy.md`: the active project-work skill and its discovery reference. `agent/extensions/megai-action-boundary/`: tool-call approval boundary that prompts only for reserved or catastrophic actions (main/release/tag/force pushes, `rm -rf` of root/home/`.git`, `git reset --hard`, local `sudo`) and blocks broad `pkill`/`killall`; routine pushes, cleanup, temp deletes, `kill <PID>` and remote `ssh … sudo` run without a prompt. `agent/extensions/megai-project-size/`: project disk-usage alert extension.
- `agent/APPEND_SYSTEM.md`: autonomy rules appended to Pi's system prompt for every model (decide ambiguous details yourself, finish the change, ask only for irreversible or user-only inputs). `agent/AGENTS.md` makes the reserved-approval list closed. A project `.pi/APPEND_SYSTEM.md` would replace this file for that project, not merge with it.
- `agent/extensions/megai-keep-going/`: on `agent_before_settle`, when a GPT/OpenAI run ends with a permission/confirmation question (or says nothing was changed), requests one continuation per user prompt with a short "decide and finish" nudge. `MEGAI_KEEP_GOING=0` disables it, `=all` applies it to every model. See its README.
- `codex/AGENTS.md`, `codex/hooks.json`, `codex/hooks/`: the same autonomy rules for Codex (`~/.codex/AGENTS.md`) and a Codex `Stop` hook running the shared classifier (continues once per turn via `decision: "block"`). `~/.codex/config.toml` is not snapshotted. Codex runs a new or changed hook only after it is trusted: open `codex`, run `/hooks` and trust `megai-keep-going` once (or after each change).
- `agent/npm/package.json` and `agent/npm/package-lock.json`: installed Pi package declarations and npm resolution; the local AgentMemory checkout is a separate path in `settings.json`, not a published package snapshot.
- `skills-inventory.json`: filenames and SHA-256 hashes of every locally installed skill tree at capture time. Third-party skill bodies and the local AgentMemory distribution are deliberately **not** republished here; settings retains the exact enabled-skill list. The installed npm packages are likewise not vendored.

## Excluded deliberately

`auth.json`, `antigravity-accounts.json`, `mcp-auth.json`, raw `mcp.json`, `models-store.json` (provider cache), `trust.json`, sessions, prompts' runtime logs, missions, receipts, backups, cache, private data, installed npm `node_modules`, third-party skill bodies and runtime state. Historical MEGAI source, legacy OMP skills/agents/config, benchmark artifacts and old Pi defaults are absent from this branch and its new root history. None are needed to describe the non-secret setup, and several contain credentials or private project/session data. Do not commit them. The snapshot is **not** a complete transferable credential or offline-install backup.

Refresh on the owner's machine with `python3 pi-current/snapshot.py`, inspect every changed file, and run a secret scan before committing. The script copies a closed allowlist, redacts all MCP headers and secret-looking MCP `env` values (`*TOKEN*`, `*KEY*`, `*SECRET*`, …), refuses differing Pi/Codex keep-going classifiers; it cannot certify arbitrary newly added paths as safe. For a new machine, install packages from the lockfile, obtain the skill trees and AgentMemory separately under their respective licenses, replace user-specific paths in the settings and MCP template, supply credentials locally, then verify in a fresh isolated Pi process. Do not overwrite a running user's config or session.
