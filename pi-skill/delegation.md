# Delegation (optional)

Load only for a real independent subtask or model failure. Direct parent work is the default. Keep the parent's selected provider, model and thinking level; role settings are guidance, not an automatic dispatcher. No child or external runner is mandatory. If no suitable connected launch/completion tool exists, do the work directly or report a real blocker, never invent a launch command.

Before delegation verify task identity, scope, acceptance, checkout/cwd, exclusive writer ownership, model/thinking and a supported completion/control path. Git writers need separate, proven task-owned worktrees; non-Git configuration writers need owned scopes and private backups. Give a child only the necessary paths and permissions. Children never delegate, mutate Plane, integrate branches or approve main/push. At most two independent children initially; do not create scouts/reviewers without a named independent need. Parent reviews the resulting full diff and tests.

If an available tool provides completion notifications, record the exact child/run identity, yield after independent work, and resume only for a matching completion/error/permission event. Never poll or sleep to wait for a child. If notifications are unavailable, use only a documented supported wait operation where safe; otherwise report the blocker. Do not resend a task merely to wait. An idle status is not test acceptance. Verify actual result and preserve evidence before transferring ownership.

Only a confirmed DeepSeek 402 insufficient-balance error permits one continuation on GPT Luna high. Auth/permission failures, shared outages, provider uncertainty or possible writes require reconciliation, not model hopping. Before changing writer, prove the old writer is quiescent and retain its diff, tests and unresolved errors. No speculative fallback, retry loop or change to the parent's active model. Preserve focused verification, approval boundaries and parent self-review.
