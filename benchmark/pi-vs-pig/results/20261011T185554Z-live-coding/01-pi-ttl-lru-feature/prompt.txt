Implement TTLCache in cache.py using Python's standard library. API: TTLCache(capacity, clock=time.monotonic), put(key, value, ttl), get(key, default=None), delete(key)->bool, len(cache). Require positive integer capacity (reject bool/noninteger with ValueError). ttl <= 0 removes any existing key and stores nothing. At clock() >= expiry, entries are expired. get of a live key promotes it to most recently used; misses return default without changing order. put replaces/promotes a live key and resets its expiry. Purge expired entries before capacity eviction and before len(); when full evict the least recently used live key. delete returns true only for a currently live removed key. Values can be None. Support arbitrary hashable keys. No threads or external dependencies. Add tests, run them, and do not modify test_public.py. Stop after verification and summarize briefly.
