# for-ustama — current Pi setup

This branch contains **only** the safe, current user-level Pi configuration snapshot in [`pi-current/`](pi-current/README.md). It intentionally does not contain the historical MEGAI source tree, OMP skills, benchmark results, or retired setup files inherited from `dev`.

The snapshot reflects the local setup at the recorded capture time. Credentials, private sessions and third-party installed code are not published; see the snapshot README for exact inclusions, exclusions and reconstruction steps. `dev` and `main` are unaffected by this branch.
